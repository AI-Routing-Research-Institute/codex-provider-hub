# 优化新版供应商页配置列

## 目标

新版供应商列表移除认证列，增加配置列，并将临时启动命令和上传检测入口集中放入配置列。

## 现状

当前上传检测按钮位于供应商名称和地址区域，末列显示认证状态；配置操作位置不集中，管理模式与普通模式列名也不一致。

## 设计范围

- 配置列始终显示；管理模式额外显示独立的“操作”列。
- 移除列表中的认证状态展示。
- 普通模式下将“上传检测”按钮放入配置列。
- 普通和管理模式下均在配置列显示“临时启动”和“上传检测”按钮。
- 管理模式在独立操作列显示隐藏和编辑操作，并保持移动端配置、操作入口均可用。
- 新版“编辑供应商”弹窗适当放大并相对页面视口水平、垂直居中；桌面端采用双列表单以避免滚动，窄屏回退单列并隐藏可见滚动条。

## 非目标

不修改认证信息读取、上传接口、服务器配置、弹窗业务逻辑或经典界面。

## 兼容性

仅新版前端布局和文案变化，无接口、配置、数据和迁移影响；使用 `patch` 版本提升。

## 风险

配置列宽度不足时按钮可能换行；通过现有响应式网格和最小宽度保持桌面、移动端可操作。弹窗固定居中并隐藏滚动条后可能在小视口超出可见区域，通过视口约束高度并保留滚轮和触摸滚动规避。

## 测试计划

运行 Vue 结构测试、JavaScript 语法检查、Vite 构建和 `git diff --check`；检查桌面与移动端按钮位置及编辑弹窗居中效果。

## 实际改动

- `proxy_static/src/components/ProvidersView.vue` 将供应商列表末列改为“配置”，移除认证状态节点；上传检测按钮固定放入配置单元格，管理模式增加独立“操作”列。
- 临时启动命令按钮从名称区域迁移至配置列，与上传检测按钮横向居中排列，并在管理模式保持显示。
- 临时启动按钮使用精简文案“临时启动”，点击后复制命令，并通过全局消息提示复制成功或失败。
- `proxy_static/src/styles.css` 为管理模式增加独立列网格，并为桌面、移动端分别安排配置与操作区域。
- 配置列的表头和按钮在桌面、移动端均居中显示；管理模式采用独立紧凑列宽，中等窗口隐藏非管理关键信息，避免配置与操作列被裁切。
- 新版编辑供应商弹窗扩大到 640px，固定在视口中央；桌面表单改为双列以消除常见视口下的滚动，窄屏恢复单列并隐藏滚动条但保留滚轮和触摸滚动能力。
- `tests/local_proxy_vue_ui.test.js` 增加配置/操作列、认证列移除和上传按钮位置回归断言。
- `tests/local_proxy_vue_ui.test.js` 增加编辑弹窗尺寸、居中、双列布局和窄屏回退断言。
- `proxy_static/dist/` 更新为 Vite 构建产物。
