# 按参考图修正控制台主题色

## 目标

让深色和浅色主题分别匹配用户提供的参考图：深海军蓝控制台、蓝灰卡片、青绿色主色，以及浅色主题的白色背景和青绿色选中态。

## 现状

当前主题仍使用上一版暖白、米色和陶土橙色，和参考图的蓝色系视觉不一致。

## 设计范围

- 仅调整主题颜色变量、状态色和已存在的字体大小规则。
- 深色主题使用深蓝黑背景、蓝灰表面和高对比浅色文字。
- 浅色主题使用白色表面、浅蓝绿色背景、深海军蓝文字和青绿色强调色。

## 非目标

- 不修改布局、间距、组件结构、业务逻辑、接口或图标。
- 不新增移动端专属设计。

## 兼容性

无接口、配置和数据兼容性影响；仅改变主题颜色和字体显示大小。

## 风险

主题变量被多个页面复用，需通过构建、契约测试和双主题浏览器检查确认对比度及状态色仍可辨识。

## 测试计划

- 运行 `npm run build`。
- 运行 `node --test tests/local_proxy_vue_ui.test.js`。
- 运行 `git diff --check`。
- 检查深色和浅色页面的实际 computed 主题变量。

## 实际改动

已在 `styles.css` 将浅色主题改为白色表面、浅蓝绿色背景、深海军蓝文字和青绿色强调色；将深色主题改为深蓝黑背景、蓝灰表面、浅色文字和青绿色强调色，并将残留固定状态色改为主题变量。保留已有字体大小调整，未修改布局、间距或组件结构。

## 验证结果

已验证：`npm run build` 通过；`node --test tests/local_proxy_vue_ui.test.js` 的 5 项测试全部通过；`git diff --check` 通过。浏览器检查确认深色主题 computed 变量为 `#071525` / `#102235` / `#16c6ba`，浅色主题为 `#eff9fa` / `#ffffff` / `#12aa9f`，body 字号为 `14px`。
