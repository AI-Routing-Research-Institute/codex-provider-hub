# 将连接信息移至页脚

## 目标

删除页脚左侧的 Key 提示，并将顶部固定连接、运行状态和数据来源信息移至页脚左侧。

## 现状

连接信息单独占用标题栏下方一整行；页脚左侧显示低价值的 Key 提示，造成垂直空间浪费。

## 设计范围

- 移除标题栏下方的连接信息栏。
- 在页脚左侧复用连接信息组件，保留状态轮询和数据源读取。
- 删除不再展示的页脚 Key 提示状态。
- 保持页脚右侧复制配置和退出中转操作不变。

## 非目标

- 不修改连接状态、运行设置、复制配置或退出中转接口。
- 不调整其他页面内容和移动端布局。

## 兼容性

无接口、配置和数据迁移影响；仅调整现有信息的展示位置。

## 风险

页脚内容增多后可能挤压右侧操作；通过生产构建和桌面页面检查确认布局不溢出。

## 测试计划

- 运行 Vue UI 定向测试和生产构建。
- 浏览器检查顶部连接栏消失、连接信息位于左下角且页脚操作正常。
- 运行 `git diff --check`。

## 实际改动

- `proxy_static/src/App.vue` 将 `ConnectionStrip` 从标题栏下方移入页脚左侧，并删除 Key 提示及其状态变量。
- 保留连接状态轮询、数据源读取、复制配置提示和退出中转行为。
- `proxy_static/src/styles.css` 将连接信息改为适合页脚的横向布局，同步减少主窗口网格行并确保页脚固定可见、右侧操作不被挤压。
- `tests/local_proxy_vue_ui.test.js` 增加连接信息位置和旧提示已删除的契约断言。

## 验证结果

- `node --test tests/local_proxy_vue_ui.test.js`：7 项通过。
- `npm run build`（`proxy_static`）：Vite 生产构建通过。
- 浏览器检查：顶部连接栏不存在；固定连接、本机状态和数据来源显示在左下角；旧 Key 提示不存在；页脚无重叠或横向溢出。
- `git diff --check`：通过，仅输出既有换行符提示。
