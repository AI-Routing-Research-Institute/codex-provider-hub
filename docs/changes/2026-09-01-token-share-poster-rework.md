# 战报海报排版修复与视觉收紧

## 目标

修复战报海报底部的文字重叠与布局失衡（"最晚一战"与页脚叠字、图例区大面积空白、请求统计信息丢失），并把整体视觉从"元素堆叠"收紧为居中轴线的海报版式。

## 现状

v1.4.1 的海报存在以下问题（用户实测反馈"下方错误严重"）：

- `最晚一战`（y=888）与页脚名称（y=892）两行文字直接重叠；
- 仅一家供应商有用量时，图例区下方留出约 120px 空白，重心下塌；
- 请求次数与成功率在海报版中丢失（v1.4.0 卡片版有）；
- 全部元素左对齐堆叠，装饰（星点、多色光晕）杂乱，缺乏统一排版节奏。

## 设计范围

- `ShareCardDialog.vue` 重写绘制布局：画布改为 600×1000；全内容居中轴线排版，统一垂直节奏（眉标/日期/副文案、狂飙区、徽章与对比胶囊、三胶囊+请求统计行、消耗构成区、最晚一战、页脚各分区间距一致）。
- 下半部分重构：环形图居中，环心显示本命供应商份额大字与供应商名（多供应商时下方水平图例，最多 5 项）；"最晚一战"独立成行并与页脚拉开安全距离；页脚合并为一行。
- 找回请求统计："N 次请求 · 成功率 xx% ·（失败 N 次）"作为三胶囊下的居中说明行。
- 装饰收紧：星点减至 40 颗，去掉青色杂光，保留品红（右上）与琥珀（左下）两团光晕；称号徽章、对比胶囊、TOKENS 字标均按居中轴线定位。
- 重建 `proxy_static/dist`。

## 非目标

- 不改后端与数据来源；不改下载/复制交互；不引入背景素材图或主题配置文件（风格常量仍内联在绘制代码中，固定不变）。

## 兼容性

- 仅前端绘制与构建产物变更；画布高度 940→1000 仅影响导出图片比例，弹窗内自适应显示不受影响。

## 风险

- 居中排版下长供应商名/长数字可能溢出：保留逐级截断省略逻辑并按宽度收缩字号；单测与浏览器实测覆盖单供应商与多供应商两种形态。

## 测试计划

- 现有 9 个 share_card 单测保持通过（纯逻辑无变化）。
- 全量：Python 单测、`node --check`、`node --test`、`npm run build`、`--smoke-test`。
- 浏览器实测出图，逐区块核对：无重叠、无越界、间距均衡。

## 实际改动

- `proxy_static/src/components/ShareCardDialog.vue`：绘制布局整体重写——画布 600×1000，全部内容改为居中轴线排版（眉标/日期/副文案/今日狂飙/大数字/TOKENS/称号徽章/对比胶囊/三胶囊/请求统计/消耗构成/环形图/图例/最晚一战/页脚按统一垂直节奏分布）。
- 修复底部重叠缺陷："最晚一战"（y=934）与页脚（y=976、分割线 y=950）拉开安全间距，页脚两行合并为一行居中。
- 找回请求统计：三胶囊下方居中显示"N 次请求 · 成功率 xx% ·（失败 N 次）（含估算）"，超宽自动降字号。
- 消耗构成区重构：环形图居中（r=76），环心显示本命份额大字与"本命 <供应商>"（fitText 宽度自适应截断）；多供应商时下方水平图例（最多 4 项），单供应商时显示"独挑今日全部用量"。
- 装饰收紧：星点 64→40，移除青色杂光，保留品红（右上）与琥珀（左下）两团光晕；徽章、对比胶囊、TOKENS 字标均居中定位。
- 重建 `proxy_static/dist`（index-ZLm8uosg.js；index.html 资产引用更新并顺带完成行末归一）。

## 验证结果

- `node --test tests/share_card.test.js`：9/9 通过（纯逻辑未变动）。
- `python -m unittest discover -s tests -p "test_*.py"`：514 个测试全部通过。
- `node --check` 语法检查与全量 `node --test` 无失败；`npm run build --prefix proxy_static` 成功；`--smoke-test` ok:true。
- 浏览器实测（17891 临时实例真实数据）：逐区块核对无文字重叠、无截断越界；"最晚一战 16:41"、页脚一行、请求统计行（41 次请求 · 成功率 87.8%）、环形图中心（100% · 本命 cai）均正确；导出 1200×2000 PNG 复核通过。
