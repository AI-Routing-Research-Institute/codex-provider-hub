# 修复时间范围精度与弹层锚定

## 目标

让时间范围弹层始终与触发选择框左边缘对齐，并在范围字段中显示和编辑日期、时分秒。

## 现状

弹层空间不足时会整体向左对齐，造成相对触发按钮偏移；日期字段只显示日期，无法编辑近 24 小时等范围的精确时分秒。

## 设计范围

- 弹层固定左边缘锚定触发选择框，空间不足时缩窄到视口剩余宽度。
- 开始和结束字段分别提供日期输入与 `HH:mm:ss` 时间输入。
- 预设范围仍按后端原有窗口值查询；只有修改日期或时间后才提交自定义精确时间区间。

## 非目标

- 不新增后端允许的时间范围。
- 不改变接口参数、预设范围语义或其他筛选项布局。

## 兼容性

无接口、配置或数据影响，仅增强前端时间编辑和弹层定位。

## 风险

浏览器时间输入控件的显示样式由系统决定；通过 `step=1` 保证秒级编辑能力。

## 测试计划

- 增加日期和时间字段、预设实际窗口与自定义转换测试。
- 运行全部 Node 测试、前端构建、JavaScript 语法检查和 `git diff --check`。
- 在桌面和 440px 窄视口验证弹层左边缘与触发器一致且不裁切。

## 实际改动

- `TimeRangeSelect.vue` 为日期字段增加秒级时间输入，并按请求筛选栏/工具栏边界计算弹层宽度，左边缘始终锚定触发框。
- `styles.css` 压缩日期时间输入布局，保持弹层与 sub2api 参考样式接近。
- 为请求筛选栏中的日期/时间输入增加 `min-width: 0` 和边框盒约束，修复原生输入控件溢出弹层的问题。
- 修复自定义范围应用后状态更新导致弹层重新打开的问题。
- `tests/local_proxy_vue_ui.test.js` 增加精确时间字段和筛选栏边界定位契约。

`node --test tests/*.test.js`（16 项通过）；`python -m unittest discover -s tests -p 'test_*.py'`（通过）；`npm run build`（通过）；JavaScript 语法检查（通过）。
