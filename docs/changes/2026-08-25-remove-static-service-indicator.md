# 删除标题栏静态运行标记

## 目标

删除控制台右上角没有控制作用的“中转运行中 / 仅监听本机”开关样式标记。

## 现状

该标记固定显示运行状态，不可交互，也不读取动态状态，与页面可访问状态及连接栏“本机可用”信息重复。

## 设计范围

- 从标题栏删除静态运行文案和开关样式标记。
- 保留控制台切换按钮、主题按钮和右下角退出中转功能。
- 增加标题栏不再渲染该标记的契约测试。

## 非目标

- 不修改服务状态接口、连接栏、退出逻辑、颜色或其他布局。
- 不清理未被本次修改触及的历史样式和组件。

## 兼容性

无接口、配置、数据和迁移影响；仅删除重复的静态展示内容。

## 风险

标题栏右侧间距可能改变；通过生产构建和浏览器检查确认剩余按钮排列正常。

## 测试计划

- 运行 Vue UI 定向测试和生产构建。
- 浏览器检查标题栏不再显示静态运行标记，剩余按钮无溢出。
- 运行 `git diff --check`。

## 实际改动

- 从 `proxy_static/src/components/Titlebar.vue` 删除静态运行文案和开关样式标记。
- 在 `tests/local_proxy_vue_ui.test.js` 增加标题栏不再渲染对应内容的契约断言。

## 验证结果

- `node --test tests/local_proxy_vue_ui.test.js`：7 项通过。
- `npm run build`（`proxy_static`）：Vite 生产构建通过。
- 浏览器检查：标题栏右侧仅保留控制台切换和主题按钮，静态运行标记已消失且布局无溢出。
- `git diff --check`：通过，仅输出既有换行符提示。
