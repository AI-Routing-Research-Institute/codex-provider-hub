# 调整新版消息提示位置

## 目标

新版界面的全局消息提示框统一从页面正上方居中弹出。

## 现状

新版消息提示框固定在右下角，移动端固定在页面底部，与期望的全局顶部反馈位置不一致。

## 设计范围

- 新版全局 toast 在桌面端固定于视口顶部中央。
- 移动端保持顶部安全边距和左右留白。
- 提高新版 toast 层级，确保从供应商、设置等任意新版页面触发时可见。
- 仅显示主体消息，不显示详细说明和状态图标。
- 关闭按钮在提示框内垂直居中。
- 保持成功、失败样式和自动消失行为不变。

## 非目标

不修改经典界面的消息提示位置、提示文案或交互行为。

## 兼容性

仅新版前端 CSS 定位变化，无接口、配置、数据和迁移影响；使用 `patch` 版本提升。

## 风险

顶部提示可能遮挡标题栏；通过限制宽度、精简为单行主体消息、顶部留白和短时自动消失降低影响。移动端使用左右固定留白，避免超出视口。

## 测试计划

运行 Vue 结构测试、全部 JavaScript 测试、JavaScript 语法检查、Vite 构建和 Python 单测；在桌面与移动视口检查提示框顶部居中，并断言经典 CSS 仍使用底部定位。

## 实际改动

- `proxy_static/src/styles.css` 将新版 toast 容器改为视口顶部居中定位，桌面端使用 16px 顶部留白，移动端使用 12px 顶部和左右留白，并将层级提高到 100。
- 新版 toast 入场方向改为从顶部向下出现。
- `proxy_static/src/App.vue` 将新版 toast 精简为主体消息和关闭按钮，不再渲染状态图标与详细说明。
- 新版关闭按钮使用两列网格垂直居中，并保留悬停和键盘焦点反馈。
- `tests/local_proxy_vue_ui.test.js` 增加新版顶部定位、移动端定位和经典界面底部定位保持不变的回归断言。

## 验证结果

- `node --test tests/local_proxy_vue_ui.test.js`：通过，21/21，覆盖单行主体消息、无图标、关闭按钮居中及经典界面隔离。
- `npm run build --prefix proxy_static`：通过，Vite 构建成功。
- `git diff --check`：通过。
- 浏览器桌面端 1280x720：toast 顶部为 16px，水平中心偏差为 0，固定定位且层级为 100。
- 浏览器移动端 390x844：toast 顶部为 12px，按可用页面宽度左右各留 12px。
- 浏览器消息样式：内容仅为“复制成功”，图标和详情节点均为 0；提示框高度 50px，关闭按钮垂直中心偏差为 0。
- 经典界面样式回归：`.toast-region` 仍为 `bottom: 24px`，未增加顶部定位。
- 完整门禁：`'' | & .venv\\Scripts\\python.exe scripts/team_policy.py pre-push` 通过，Python 单测 521/521、全部 JavaScript 测试通过、构建和语法检查通过。
