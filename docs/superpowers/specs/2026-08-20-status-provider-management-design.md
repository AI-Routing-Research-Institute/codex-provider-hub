# 状态服务供应商管理设计

## 目标

在本地中转控制台新增“监控管理”页面，管理远程状态服务上的全部供应商，支持查看、排序、删除和立即检测。

## 架构

- 浏览：前端读取状态服务公开 `/api/status`，读取完整配置通过本地后端转发到受限 SSH。
- 修改：复用现有强制命令 SSH 通道，向 `status_provider_import.py --serve` 发送管理动作 JSON，不新增公网管理 API。
- 排序：远端写入 `providers.d/.order.json`，状态服务配置加载器在合并主配置和片段后按该顺序排列。
- 删除：远端删除主配置或 providers.d 片段、对应凭据和公开状态数据库记录，修改失败自动回滚并重启 Worker。

## 页面

新增“监控管理”标签，显示全部远程供应商的名称、地址、模型、状态和最近检测时间。每行提供上移、下移、立即检测、删除操作；删除必须二次确认。排序保存后立即重载 Worker。

## 安全与兼容

所有凭据和修改请求仅经过 SSH；公开状态服务只用于读取状态和提交立即检测任务。现有主配置供应商和已上传供应商统一纳入管理，旧配置没有顺序文件时保持原文件顺序。

## 测试

覆盖顺序文件加载、删除主配置/片段、重复删除、回滚、管理动作 SSH 编排、前端标签和操作按钮；运行完整 Python/JavaScript 测试与 PyInstaller 冒烟验证。
